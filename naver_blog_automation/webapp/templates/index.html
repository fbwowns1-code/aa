네이버 블로그 자동화 제어판

부서별 진행 현황

대기 중

1. 계정

계정 추가 / 수정

비밀번호는 로그인 폼에 자동 입력하는 용도로만 쓰이고 이 화면에 다시 표시되지 않는다. 저장 후에는 터미널에서 python -m departments.onboarding_publishing --account 계정이름을 한 번 실행해서 세션을 만들어야 실제로 로그인이 된다.

2. 지침

지침 새로 쓰기 / 수정하기

3. 실행

여기서 실행하면 항상 완전 자동 모드로 진행된다(제목 1번 자동 채택, 중간에 수정 요청 불가). 턴마다 대화하면서 고치고 싶으면 터미널에서 python main.py를 직접 실행한다.
