# 네이버 블로그 포스팅 자동화

키워드 하나만 입력하면 다음을 자동으로 수행한다.

1. GPT + 웹 검색으로 F목록(사실 목록)·출처·제목 45/50개 생성 (`prompts/system_prompt.txt` 지침의 턴1)
2. 제목 자동 선택 → 본문 작성 → F목록 대조 팩트체크 → 최종본 (턴2)
3. 이미지 프롬프트 생성(턴3) → OpenAI 이미지 생성 API로 실제 이미지 파일 제작
4. Playwright로 네이버 블로그 글쓰기 에디터에 제목/본문/이미지를 채우고 **임시저장**까지 진행

`prompts/system_prompt.txt`는 사용자가 Claude 프로젝트에 저장해둔 "IT/자동차 네이버 블로그 홈판 프롬프트 v7.0" 지침 원문 그대로이며, 맨 아래에 자동화 파싱용 JSON을 추가로 뽑아내는 "자동화 어댑터" 섹션만 덧붙였다. 지침 자체(턴 구성·제목 규칙·본문 규칙·팩트체크·이미지 규칙)는 전혀 바꾸지 않았다.

## 이미지에 대한 중요한 결정

본문에 넣을 이미지는 **웹에서 이미지를 가져와 가공("이미지 세탁")하는 방식은 구현하지 않았다.** 타인의 저작물을 역검색·저작권 탐지를 피해 재사용하는 것은 저작권 침해 회피 수단이기 때문이다. 대신 두 경로를 쓴다.

- **실사 이미지**: 턴3의 실사 프롬프트를 그대로 **OpenAI 이미지 생성 API(`gpt-image-1`)**에 넣어 매번 새로 생성한다(`src/image_gen.py`). GPT API 키 하나로 처리된다.
- **한글 인포그래픽 썸네일**: 기본값은 **챗지피티 웹채팅(chatgpt.com) 자동화**다(`src/chatgpt_image.py`). 턴3에서 나온 인포그래픽 프롬프트를 실제로 챗지피티 채팅창에 붙여넣고, 생성된 이미지를 다운로드해서 저장한다.

**챗지피티 웹채팅 자동화에 대한 주의**: OpenAI 이용약관은 챗지피티의 사람용 웹 제품에 대한 프로그램적/자동화 접근을 금지하고 있다. 이 방식은 API가 아니라 브라우저로 채팅 화면을 흉내 내는 것이므로, 계정이 제재될 수 있는 위험을 감안하고 쓰는 기능이다. 이 위험을 피하려면 실행할 때 `--no-infographic-via-chatgpt`를 붙이면 인포그래픽도 이미지 생성 API로 만든다.

유명인의 실제 얼굴을 그대로 그리는 프롬프트는 (API든 챗지피티든) 정책상 거부될 수 있다. 실패한 이미지는 건너뛰고 나머지는 계속 진행하도록 되어 있으니, 필요하면 지침의 유명인 관련 장치(1·20번) 사용을 줄이는 것을 권장한다.

## 설치

```bash
cd naver_blog_automation
pip install -r requirements.txt
playwright install chromium

cp .env.example .env
# .env를 열어 OPENAI_API_KEY를 채운다
```

## 최초 1회: 네이버 로그인 세션 저장

네이버 계정 비밀번호는 코드에 저장하지 않는다. 브라우저 창에서 직접 로그인하면 그 세션(쿠키)만 로컬 파일로 저장해 재사용한다.

```bash
python -m src.naver_login
```

브라우저가 뜨면 직접 로그인 → 터미널로 돌아와 Enter → `naver_session.json` 저장 완료.

이 파일이 있으면 이후 실행에서는 로그인 없이 바로 글쓰기 화면으로 들어간다. 네이버 세션은 일정 기간 후 만료되므로, 자동화가 로그인 페이지에서 멈추면 이 스크립트를 다시 실행한다.

## 최초 1회: 챗지피티 로그인 세션 저장 (인포그래픽을 챗지피티 웹채팅으로 만들 경우)

`--no-infographic-via-chatgpt`를 쓰지 않는 이상(기본값) 필요하다. 위의 이용약관 위험을 감안했다면:

```bash
python -m src.chatgpt_login
```

브라우저가 뜨면 챗지피티에 직접 로그인 → 터미널로 돌아와 Enter → `chatgpt_session.json` 저장 완료. 이 계정은 GPT API 키와는 별개로, 실제 챗지피티 로그인 계정(무료든 Plus든)이어야 한다.

## 실행

```bash
python main.py --keyword "쏘렌토 풀체인지 MQ5" --blog-id 내블로그아이디
```

기본 모드는 **대화형**이다. 지침 원문에 있는 "제목 번호를 골라달라"와 "수정할 곳이 있으면 말해달라" 지점에서 실제로 멈춰서 터미널 입력을 기다린다. 이때:

- **숫자**를 입력하면 그 번호의 제목/그대로 진행으로 처리된다.
- **문장**을 입력하면 수정 요청으로 그대로 모델에 전달되고, 같은 턴을 다시 받아서 또 보여준다 — 예를 들어 제목 목록이 나왔을 때 `"오너 감정형 위주로 5개만 다시"`, `"가격 정보를 제목에 넣어줘"`, 본문이 나왔을 때 `"3번째 소제목에 연비 얘기 추가해줘"`, `"말투를 좀 더 담백하게"`, 이미지 프롬프트가 나왔을 때 `"메인 이미지 배경을 도심으로"` 같은 식으로 몇 번이든 반복해서 수정을 요청할 수 있다.
- 아무것도 입력하지 않고 그냥 Enter를 누르면 본문/이미지 단계는 "수정 없음"으로 다음 단계로 넘어간다(제목 단계는 번호를 입력해야 넘어간다).

주요 옵션:

| 옵션 | 설명 |
|---|---|
| `--keyword` | 키워드 또는 완성된 제목, 참고 본문이 있으면 `--reference`와 함께 |
| `--reference` | 참고 본문(기사·타 블로그 등, 팩트 소스로만 사용됨) |
| `--extra` | 시작할 때부터 반영하고 싶은 요청사항(예: `"경쟁사 A 모델은 언급하지 말아줘"`) |
| `--image-mode` | `실사` / `인포` / `둘다` (기본값 `둘다`) |
| `--title-index` | 제목 번호를 미리 고정해서 대화형 프롬프트 자체를 생략한다 |
| `--blog-id` | `blog.naver.com/이 부분` |
| `--headless` | 브라우저 창 없이 실행 (처음에는 끄고 눈으로 확인하는 것을 권장) |
| `--no-pause` | 임시저장 직전 확인 절차 생략 (처음 실행할 때는 권장하지 않음) |
| `--auto` | 대화형 확인 자체를 끄고 각 턴을 기본값(제목 1번, 수정 없음)으로 끝까지 자동 진행 |
| `--no-infographic-via-chatgpt` | 인포그래픽 썸네일도 챗지피티 웹채팅 대신 이미지 생성 API로 만든다 |

기본값(`--no-pause` 미지정)은 에디터에 내용을 다 채운 뒤, **임시저장을 누르기 전에 터미널에서 Enter 입력을 기다린다.** 브라우저 창에서 실제로 제목·본문·이미지가 잘 들어갔는지 눈으로 확인한 뒤 Enter를 눌러야 저장된다. 몇 번 돌려서 안정적으로 동작하는 걸 확인한 뒤에 `--auto --headless --no-pause`로 완전 무인 자동화하는 걸 권장한다.

## 선택자가 깨졌을 때

네이버와 챗지피티 둘 다 UI(DOM 구조·클래스명)를 예고 없이 바꾼다. `src/naver_poster.py`(`TITLE_SELECTORS` / `IMAGE_BUTTON_SELECTORS` / `SAVE_BUTTON_SELECTORS`)와 `src/chatgpt_image.py`(`PROMPT_INPUT_SELECTORS` / `SEND_BUTTON_SELECTORS` / `NEW_CHAT_SELECTORS` / `GENERATED_IMAGE_SELECTORS`) 상단에 후보 선택자가 여러 개 들어 있지만, 전부 실패하면:

1. `--headless` 옵션을 빼고 실행해서 브라우저 창을 직접 본다.
2. 막힌 지점에서 F12(개발자도구)로 해당 요소의 클래스명/속성을 확인한다.
3. 해당 상수 리스트 맨 앞에 새 선택자를 추가한다.

## 유의사항

- 네이버 블로그 이용약관상 자동화 도구 사용에 제약이 있을 수 있으니, 본인 계정에서 과도한 빈도로 돌리지 않는 것을 권장한다. 이 스크립트는 **임시저장까지만** 하고 실제 발행(공개)은 하지 않는다 — 최종 검토·발행은 직접 하는 것을 전제로 만들었다.
- OpenAI 웹 검색 tool 이름(`OPENAI_WEB_SEARCH_TOOL`)은 계정/모델에 따라 `web_search_preview` 또는 `web_search`일 수 있다. 실행 중 tool 관련 에러가 나면 `.env`에서 값을 바꿔본다.
- 생성된 이미지·본문에 포함된 가격·스펙 등 사실 정보는 지침의 팩트체크 절차를 거치지만, AI가 만든 콘텐츠이므로 발행 전에 한 번은 직접 훑어보는 것을 권장한다.
